# Alkebulan Flow portfolio package

## One-line case study

Alkebulan Flow helps small service businesses turn scattered client work into one visible, prioritized operating system—with AI-assisted briefs that remain useful even when no model credential is configured.

## 60–90 second walkthrough

1. Open the Overview and frame the four operating signals: active work, deadlines, pipeline, and completion.
2. Point out the revenue trend and AI-assisted project-health warning.
3. Open Projects and Clients to show the relationship between delivery progress and account value.
4. Open Tasks, create “Prepare stakeholder handoff,” and move one card between columns.
5. Open Flow AI, generate the Website launch brief, then show risks, next actions, and the client-update draft.
6. Resize to mobile and close with the contact-free, responsive demo experience.

## Case-study talking points

- Designed for operators, not generic project-management complexity.
- Uses progressive disclosure: the overview identifies risk; project and task views support action.
- Separates deterministic demo behavior from credential-backed production integrations.
- Keeps public portfolio content free of personal contact details.
- Uses typed domain data, validated API input, and a structured AI response contract.

## Deployment checklist

1. Push the repository to a Git host.
2. Import it into Vercel and keep the framework preset as Next.js.
3. Run `npm run build` locally before each release.
4. For stateless demo deployment, no environment variables are required.
5. Before production usage, provision PostgreSQL, identity, object storage, rate limiting, and `AI_GATEWAY_API_KEY`.
6. Re-run the security and accessibility checklist after production services are connected.
